Core Concepts

The Quantum Framework is an advanced JavaScript library for building reactive user interfaces. It is designed around the principle of declarative state management and a highly optimized, reactive data flow. Understanding these core concepts is crucial for building efficient and scalable applications.

Immutable State Tree

All application state is stored within a single, immutable state tree. This ensures predictability and simplifies debugging. To change the state, you must dispatch an event. An event is a plain object describing what happened. The state tree itself is never mutated directly.

JavaScript Example
// Dispatch an event to update the state const store = createStore(); store.dispatch({ type: 'USER_LOGIN', payload: { userId: 'q-123' } });
Note

Immutability is enforced by the framework. Direct mutation of the state object will throw an error in development mode.

Predictable

State changes follow a strict unidirectional flow, making your application behavior predictable and easy to understand.

Debuggable

Every state change is logged and can be traced, making debugging much easier compared to mutable state models.

Efficient

With immutable data structures, change detection becomes fast and efficient through simple reference checks.

Reactive Data Flow

When the state tree is updated via an event, the framework reactively updates all components subscribed to that part of the state. This is achieved through a high-performance virtual DOM diffing algorithm, ensuring minimal and efficient updates to the actual DOM.

Quantum Framework's unidirectional data flow architecture

The diagram above illustrates the unidirectional data flow. Actions are dispatched from the UI, processed by the store, and the new state flows back down to the UI components, causing them to re-render.

Warning

Avoid direct DOM manipulation when using Quantum Framework as it can interfere with the reactive rendering system and cause unpredictable behavior.

Component System

Quantum Framework uses a component-based architecture that allows you to build encapsulated components that manage their own state, then compose them to make complex UIs.

JavaScript Example
// A simple Quantum component const Welcome = component(({ name }) => { return h('div', { class: 'welcome-message' }, `Hello, ${name}!`); });

Side Effects

Side effects are managed through a dedicated system that keeps them separate from your pure components, making your code easier to test and reason about.
